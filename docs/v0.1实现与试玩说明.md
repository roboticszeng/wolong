# v0.1 后方经营切片

此文为第一版实现记录。当前界面已全部重做，操作方式与截图请以README和[v0.2界面重做说明](v0.2界面重做说明.md)为准。

日期：2026-10-01。Godot 4.7.2 / GDScript / Compatibility。

## 范围

实现设计大纲第16.3节的成都—汉中经营闭环，可以从223年五月玩到224年十月并获得筹备复盘。不是223—228年完整首版。

包含地方库存、四类资源、持续运粮政策、仓储三阶段、粮道整备、人物委任、个人督办、月度结算、自动暂停、预览、因果日志与存档。Godot中新增「卧龙筹备」参数面板，可编辑常用参数并直接试玩。

南中、北伐、其余技术、敌方行动、完整人物关系与音效尚未接入。当前数字是试玩参数，资源不是历史计量单位。

## 实际规则

- 开局成都90粮、汉中30粮、80钱、60军需。成都70劳力、汉中30劳力；常规农业、守备与生产已占42和18，余量供工程和运输使用，不能永久囤积劳力。
- 每月常规收入4钱、维护3钱，军需净补充0.5，基线支出和劳力包含常规工坊。成都月耗4粮、汉中月耗2粮；九月成都收80、汉中收20。项目和运输额外扣输入，不能预支收成。
- 仓储基础月损0.5%；成都试点后0.3%，稳定执行后0.15%；推广后汉中0.15%。收益替换旧规则，完成后的下一月生效。
- 基础粮道容量12、损耗10%；整备后容量20、损耗6%；均需一月到货。每发1粮使用成都0.75劳力和0.05钱。工程先分配劳力，运输按余量执行。来源保留20粮，汉中与在途目标60粮。
- 采购在购买地点生效，每次最多12粮、每粮0.5钱；各地区每收获周期最多采购24粮，九月重置。可以变卖10军需筹5钱，但要保留最低库存。
- 同一负责人不能主持两个执行项目。专长匹配缩短一月；暂停保留进度和已付启动费，恢复不会重复收费。
- 督办占一格精力，原本超过两月的阶段首月可多推进一月，但不能省掉实际投入。督办降低健康，授权时可恢复；暂未加入疾病、死亡判定。
- 必需开销无法支付时拒绝月度推进，清楚说明当地缺口；不将负数归零继续产出。可选项目缺输入则暂停并报告。完整饥荒、欠饷等危机演化留待后续接入。
- 自动推进逐月使用与手动相同的结算；项目完成、收获、低库存、受阻或筹备结束时暂停。

## 试玩

双击根目录「启动游戏.cmd」。委任蒋琬做仓储试点、李严整备粮道；项目页可以向下滚动。打开每月8粮的运粮政策，推进到重要节点，再继续投入仓储下一阶段。224年十月检视仓储推广、粮道整备、汉中粮≥50、钱≥10四项成果。

空格推进一月，Ctrl+S保存，Esc暂停；界面「帮助」显示规则和存档位置。损坏存档、嵌套字段错误和与当前参数表不一致的存档会被拒绝，当前游戏不变。新存档保留上一版.bak。参数表修改后重启游戏；继续旧档需要恢复原参数表。
