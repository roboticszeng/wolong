# v0.2 场景界面重做

2026-10-01。按用户要求废弃v0.1的表格、常驻长文字和小地图布局，使用城市与地图作为主界面。

## 主屏

成都和汉中有独立全屏场景；上方资源图标与年月，底部指令图标、推进时间，左下诸葛亮头像与一句提示。没有开局说明墙、常驻项目表或四个文档式页签。

点粮仓做仓储改良；点官署看人物；点城门安排粮道；点集市采购；点田地看收获。设施标签和建筑范围都可以点击。操作卡只在选中后出现，委任通过头像选人，投入显示图标和数字，阶段用进度条表现。开工后收起面板回到场景。

舆图铺满主屏，显示城池、路线、地方粮库及移动的车队；点城市直接进入对应城镇。行人、河面、炊烟和运粮动态由引擎绘制；完成仓储改良或粮道整备会留下场景标记。仓储采用标记遵守实际地区，不把成都试点当成汉中已经采用。

账目放在「奏报」的详细入口，快捷预览不改变游戏。最终复盘改为图标成果、人物与简短台词；保存、读档、新局、帮助收进右上菜单。

## 美术

使用内置imagegen生成成都、汉中、区域舆图和四个人物的头像图集，保存于game/assets/original。完整文件和提示词见同目录「生成记录.md」。参考《中国式家长》的场景中心和人物呈现、《三国志》的城池、地图与指令布局，没有复制原游戏素材。

B.B.Bits免费NPC继续用于行走动画，既有许可限制仍适用。没有将该作者素材送入生成工具。原村庄样包保留，但不再作为缩小主地图的建筑贴图使用。

## 验证与范围

49项经营/存档检查与21项新版界面检查通过；真实图形窗口中检查城镇、委任、地图、汉中、集市、预览、缩小窗口和最终复盘。界面测试从开局走完224年十月的完整筹备流程。

这次重做界面与表现，仍是成都—汉中的经营切片。南中、北伐、其余技术和223—228年完整流程尚未接入。当前规则表与旧存档版本保持兼容。
